# Сверка — сравнение прайсов XLSX и CSV

Бесплатный инструмент с локальной обработкой файлов в браузере. Сопоставление по артикулам, изменения цен, новые и исчезнувшие позиции, отдельные дубли и ошибки, отчёт XLSX.

Открыть: https://dimarrter.github.io/sverka/

Файлы до 8 МБ и 20 000 строк, цены в одной валюте и с одинаковыми условиями НДС. PDF и поиск похожих названий не поддерживаются.

Включены ExcelJS и Papa Parse с их лицензиями MIT.
